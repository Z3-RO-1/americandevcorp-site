ADC Write Support

ADC Write is an independent local writing app for macOS 14 or later.

Create, open and save

  1. Choose New Document or a template on Home. Each document opens in its own tab.
  2. Use Open Document to choose an existing .fwrite, DOCX, RTF, text or HTML document.
  3. Save as .fwrite to retain native formatting, comments and tracked text edits. Imported originals are retained in the native document.

Export and independent file exchange

Use Import / Export or Share to export DOCX, PDF or plain text, or send a native copy through a service you choose. To store a document in ADC Files, save or export it from ADC Write, then import it into ADC Files. Export from Files and open that copy in Write when needed. The apps do not need each other running.

Permissions and autosave

Use the file picker to authorize documents. The Store edition may request the parent folder when you rename, duplicate or move a file. Choose your default save folder under Settings → Saving. After the first Save, autosave writes changes following a short pause when enabled. If another editor changes the file, ADC Write refuses to overwrite it; save a separate copy instead.

Versions, recovery and Trash

Version History previews and compares saved native versions. Restoring preserves your current draft first and pauses autosave until you explicitly save the restored text. Recovered drafts are available under Import / Export. Documents moved to ADC Write Trash can be restored without overwriting another file at the original location. Keep a separate backup for protection against loss of the Mac.

Compatibility

ADC Write is not Microsoft Word and does not promise full Word feature compatibility. DOCX and PDF exports are clean copies without native comment or tracked-edit history. Formatting changes are not tracked. Complex Word layouts, true footnotes and real-time online collaboration are not supported. Keep the native file and review exported documents before sending them.
