ADC Files Support

ADC Files is an independent local file library for Mac and iPhone.

Connect your devices without cloud hosting

  1. Open Nearby Sync in ADC Files on both devices. Keep the Mac awake and use the same local Wi-Fi network.
  2. Choose Find Nearby Devices, select your device and accept its invitation.
  3. For a new pairing, compare the code on both screens and confirm only if the codes match.
  4. Select files or folders and choose Sync Selected. Automatic checks can exchange later changes while both Nearby Sync screens remain open.

Allow Local Network access when prompted. Guest networks can prevent discovery. This mode does not provide sync across unrelated remote networks, and iPhone backgrounding can end a transfer.

Files, versions and interruptions

Native file formats stay unchanged. Received files appear in Nearby Files; previous contents remain available through Version History. Conflicting edits retain a separate conflict copy. Deletions stay local. If a connection is interrupted, reopen Nearby Sync and retry; incomplete files are not published as completed files.

Backups

On Mac, choose your own recovery folders in Backups settings and review verification status. Store-edition scheduled recovery runs while the app is open and catches up when reopened. Keep recovery copies on another physical drive for protection against a drive failure.
