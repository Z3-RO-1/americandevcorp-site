ADC Canvas Support

ADC Canvas is a free local canvas editor for Mac. No account or paid hosting is required.

Getting started

  1. Choose Create new canvas.
  2. Use the add menu to create titles, paragraphs, folders or import an image/PDF.
  3. Arrange items, connect nodes and add notes or comments.
  4. Return Home to reopen saved canvases. Changes save locally.

Import and export

Open compatible ADC Canvas JSON files with Open. Use a project’s actions to export a canvas or a review package. Keep original files and test an exported copy before discarding anything.

Appearance and recovery

Use Appearance in the sidebar for Light, Dark or System. Keep independent backups of important canvases and their attachments. Local recovery copies do not replace an external backup.

What is included

This release supports local canvas editing, relationships, text, folders, imported media, comments, search and file export. It does not include a Codex connection, an account, an agent service, hosted collaboration or automatic cloud sync.

Contact support

Use the support contact on AmericanDevCorp.com and include ADC Canvas, your app/macOS version and steps to reproduce the issue. Do not include private content unless you intend to share it.
