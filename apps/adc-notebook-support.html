ADC Notebook Support

ADC Notebook is a free local notebook app for macOS 14 or later. No ADC account is needed.

Getting started

Use + to create a notebook, section or page. Select a page to write, format text, add checklists and attachments, or work on its canvas and drawings. Notes save automatically; Save Library flushes pending changes.

Backups and recovery

Use Settings & backups to export a complete library. A notebook context menu exports a complete notebook file. Import a notebook file or library backup to add a copy while retaining existing notes. Page history restores saved revisions; recently deleted pages and deleted notebooks or sections have separate recovery controls. Keep an independent copy of important exports.

Files and compatibility

ADC Notebook uses .folio notebook files and .folioclip clippings. Import tools accept supported text, HTML, Markdown and notebook exports; inspect the import preview before confirming. This app does not directly open every proprietary OneNote database or promise lossless conversion of all note formats.

Optional connections

Nearby transfer requires both peers to start sharing and approve the connection. You can also share exported files using macOS. Web clipping contacts only websites you choose. Server connections require your own compatible server; no hosted sync service is included.

Appearance and protected sections

Settings & backups includes Light, Dark and System appearance. Protected sections lock when the app becomes inactive. Forgotten passwords cannot be recovered.

Contact support

Use the company contact information at AmericanDevCorp.com. Include your macOS version, app version and steps to reproduce the issue. Avoid sending personal notes, recovery keys or passwords.
