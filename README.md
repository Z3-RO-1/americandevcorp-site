# americandevcorp.com

Static site for American Dev Corp and Gilbert Aguirre.

## Structure

- `index.html` - landing page
- `about.html` - profile and company overview
- `projects/` - project directory
- `policies/` - company and project policy pages
- `CNAME` - custom domain for GitHub Pages
- `.nojekyll` - deploy static files directly

## Suggested hosting

GitHub Pages with the custom domain `americandevcorp.com`.
